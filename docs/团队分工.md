# 团队分工

本项目为四人无障碍黑客松项目。为避免 git 冲突，**每人只提交自己所属目录的改动，不跨目录修改**。

## 分工表

| 成员 | 职责 | 负责目录 | 说明 |
|---|---|---|---|
| 成员 A | 前端开发 | `frontend/` | Demo 页面、无障碍交互、TTS 播报 |
| 成员 B1 | 后端开发（感知层） | `backend/perception/` | 视觉/听觉/语音识别服务 |
| 成员 B2 | 后端开发（决策层） | `backend/decision/` | 融合决策与规则引擎 |
| 成员 C | 产品需求 | `docs/` | 产品方案、功能清单、接口契约 |
| 成员 D | 路演主讲 | `demo/` | 演示脚本、视频素材、现场串讲 |

> 注：后端拆分为感知层（B1）与决策层（B2）两人份，通过统一数据结构契约解耦，可并行开发互不等待。`README.md` 由团队共同维护，改动时在群内同步。

## 协作约定

1. 每人只改自己目录下的文件，避免跨目录改动。
2. 接口契约以 `docs/api.md` 为准，前后端改动需同步更新该文件并告知对方。
3. 所有提交消息使用中文，前缀标注模块，如 `feat(前端): 新增场景卡片`。
4. 代码推送到 `main` 分支。
5. 演示素材统一存放到 `demo/videos/`，按场景分子目录命名 `NN_场景名/`。
