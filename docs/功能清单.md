# 功能清单

## 一、感知层（后端 1）

| 模块 | 功能 | 状态 | 说明 |
|---|---|---|---|
| 视觉分析 | 场景描述、物体识别、障碍/危险检测 | ✅ 已实现 | Qwen-VL（OpenAI 兼容），无 Key 降级 mock |
| 视觉分析 | OCR 文字识别（读药品/门牌） | ⬜ 待接入 | 预留 PaddleOCR |
| 视觉分析 | 深度估计（台阶/悬空） | ⬜ 待接入 | 预留 Depth Anything V2 |
| 听觉识别 | 环境声音事件（鸣笛/警报/门铃） | ⬜ 待接入 | 预留 YAMNet/PANNs，当前 mock |
| 语音识别 | 语音指令转写 + 意图识别 | ⬜ 待接入 | 预留 FunASR/SenseVoice，当前 mock |
