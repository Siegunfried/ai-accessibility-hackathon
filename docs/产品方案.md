# 产品方案

## 一、产品定位

「视碍守护」是一款面向视障人士的**视觉 + 听觉智能提醒系统**。通过摄像头与环境麦克风实时感知周围世界，用**语音**向用户播报障碍、危险、文字与场景信息，让视障人士「看见」世界、听见安全。

## 二、目标用户

- 全盲、低视力人群
- 康复训练中的中途失明者
- 视障人士陪护者（辅助使用）

## 三、核心痛点

1. **出行避障难**：盲道被占、障碍物、台阶、来车等危险缺乏及时提醒。
2. **信息获取难**：无法阅读药品说明书、门牌、票据等文字信息。
3. **环境感知难**：听不到或难以判断鸣笛、警报、门铃等关键声音的方向与含义。
4. **独立出行难**：问路、乘车、过马路高度依赖他人协助，缺乏随身智能辅助。

## 四、解决方案

| 痛点 | 能力 | 实现 |
|---|---|---|
| 出行避障 | 视觉障碍检测 + 方位/距离播报 | Qwen-VL 场景理解 + YOLO/Depth |
| 信息获取 | 文字朗读（OCR） | PaddleOCR |
| 环境感知 | 声音事件识别 | YAMNet / PANNs |
| 语音交互 | 语音问路、指令识别 | FunASR / SenseVoice |
| 分级提醒 | 合成语音播报 | edge-tts / 前端 TTS |

## 五、系统架构

```
前端 Demo（展示 + TTS）
      │  POST /api/decide
      ▼
后端 2 决策层（融合 + 规则引擎）
      │  HTTP
      ├──────────────┐
      ▼              ▼
后端 1 感知层      后端 1 感知层
 · 视觉(Qwen-VL)   · 听觉(YAMNet)
 · OCR            · 语音(FunASR)
```

## 六、核心亮点（无障碍设计）

1. **分级提醒**：高危（语音+震动）> 提示（语音）> 普通（语音），按风险强弱配置提醒强度。
2. **多模态融合**：视觉、听觉、语音意图三者融合，例：过马路时「看到来车 + 听到鸣笛」双重确认后告警。
3. **离线降级**：任何模型未配置/失效时自动降级为 mock 数据，保证演示与基础能力不中断。
4. **可访问前端**：高对比度、大字号、屏幕阅读器支持（`aria-live`）、键盘可操作、`prefers-reduced-motion` 适配。
